# Praxis Church OS — shareable mockup

A click-through prototype of a church management console, built around **Destiny Sanctuary
Int'L, Nyahururu** — their service times, ministries and national conferences.

**Live:** https://maxblessngugi.github.io/praxis-mockup/ — the landing page explains what the
console covers; its button opens the console itself.

| File | What it is |
| --- | --- |
| `index.html` | The landing page. Hand-written; the only file you edit by hand. |
| `Praxis-Church-OS-Mockup.html` | The whole console in one HTML file (React, Tailwind and the icon font inlined). Opens offline. |
| `home.png` | The dashboard screenshot used as the landing page's hero. |
| `og-preview.png` | The 1200×630 card a WhatsApp/Twitter link to the site shows. |

Sources live in the `praxis` repo (the app) and the `PRAXIS` deliverables repo (this site, the
built artifact and the tools that regenerate it). `.nojekyll` keeps GitHub Pages from running the
files through Jekyll.
